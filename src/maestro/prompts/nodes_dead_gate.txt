A menu choice is GATED on state (a `requires` flag/variable) that no EARLIER scene ever raises — the
gate can never open, so that branch is dead. The TARGET names the scene and the state it gates on.
{{include:tool_call_rule}}

Fix it ONE of two ways:

  - RAISE the state earlier: in a scene that plays BEFORE this one (from SCENES), add an effect on a
    line that raises it —
        edit_node(node_id="<an earlier scene>", line_index=<N>, effects=[{"set_flag":"<the flag>"}])
    (for a counter use effects=[{"add_var":{"var":"<name>","amount":1}}]). Pick a line that has no
    effects yet, so you don't overwrite existing ones. Now the gate can open.

  - DROP the gate: rewrite this node's `end` so that choice carries no `requires` — an ending can be
    earned by the story, not a variable:
        edit_node(node_id="<the gated scene>", end={"type":"menu","choices":[{...no requires...}]})

Fix only the ONE named flag/variable. Do not invent unrelated state, and keep at least one ungated
choice in the menu.
