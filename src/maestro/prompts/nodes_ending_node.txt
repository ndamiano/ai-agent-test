The story declares an ENDING that has no scene to play it. The TARGET names the ending id(s) that
are missing a node. Author the ending scene. {{include:tool_call_rule}}

Create the scene with the ending's EXACT id and make it END the game:
    write_node(node_id="<the exact ending id from the TARGET>",
               content={"lines":[ ...the final scene... ], "end":{"type":"end"}})

The node_id MUST be the ending id spelled EXACTLY as the STORY block lists it (e.g. "ending_solitude")
— not a renamed or new id — so the paths that target it resolve. Dramatize the ENDING the STORY block
describes for that id: the concrete final moment, in the characters' own words, using the EXACT
character ids from the cast. Give it a `location` (a background id) and real lines; the `end` is
{"type":"end"} because the arc resolves here.
