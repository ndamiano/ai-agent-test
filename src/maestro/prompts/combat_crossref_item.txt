A combat piece gates on an ITEM that no game item declares. The TARGET names the exact site, e.g.
`abilities[drink_potion].requires.item: 'elixir' is not a declared item`.

Fix it by RE-AUTHORING that one slice with its write tool shown under the skeleton below (usually an
ability → write_ability; an encounter condition → write_encounter), keeping every other field. Two
valid fixes:

  - Repoint to a real item — set the gate's `item` to an EXACT id from the ITEMS list below, if one
    fits the intent (an ability that consumes a potion should name the potion the world hands out).
  - Otherwise DROP the gate: re-author the slice WITHOUT that `requires.item`. An ability must not
    require an item the game never gives the player.

Combat does not add items to the catalogue — it points at an existing one or drops the gate. An item
id is a plain STRING. Fix only the named site; restate the slice's other fields.
