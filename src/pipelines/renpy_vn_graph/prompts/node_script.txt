## Ren'Py Syntax Reference
label node_id:                       — first line (required, use exactly: label {node_id}:)
    scene bg_id with dissolve        — set background
    show char_id at left             — show character left
    show char_id at right            — show character right
    show char_id at center           — show character centered (only when alone)
    hide char_id                     — hide character sprite
    "Narrator text."                 — narration (never write: Narrator "text")
    char_id "Dialogue line."         — character speaks (use the id, not the name)
    menu:                            — player choice (branch nodes only)
        "Choice text A":
            jump target_node_id_a
        "Choice text B":
            jump target_node_id_b
    jump next_node_id                — proceed to next node (beat/root nodes)
    "The End."                       — ending nodes only
    return                           — ending nodes only, after "The End."

Every line inside a label block MUST be: a quoted string, char_id "text", a Ren'Py keyword, or a menu option. Bare prose and asterisks are syntax errors.
Do not write show char_id at pos, speaking or show char_id at pos, not_speaking — speaker highlighting is injected automatically.
