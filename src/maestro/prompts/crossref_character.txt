A dialogue line names a SPEAKER that is not one of this game's characters. The TARGET names the
node and line, e.g. `nodes[ending_command].lines[1].speaker: 'mara_lin' is not a declared character`.

Fix ONLY that one line. Set its speaker to one of the EXACT character ids listed under CHARACTERS
below, or to null if the line is narration:

    edit_node(node_id="<the node in the target>", line_index=<N>, speaker="<an id from CHARACTERS>")
    edit_node(node_id="<the node in the target>", line_index=<N>, speaker=null)   // narration

The speaker is a PLAIN STRING id, or null. It is NEVER an object ({"id": "..."} / {"name": "..."})
and NEVER a list. Do NOT invent a new character and do NOT rename an existing one — the cast is
fixed; choose from the list. If no listed character fits, the line is narration: use null.
