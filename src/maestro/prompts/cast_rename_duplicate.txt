Two characters share the SAME id — the TARGET names the duplicated value, e.g.
`characters.characters has duplicate values: ['mara']`. Two people cannot share one id; ONE of them
must be renamed to a new, unique snake_case id.

There is no per-character edit tool, so fix through the whole component WITHOUT re-authoring anyone:

  1. read_component("characters") to get the current cast verbatim.
  2. Decide which of the two colliding entries keeps the id and which gets a NEW unique id — pick one
     that fits that person (e.g. 'mara_lin' vs 'mara_okonkwo').
  3. write_component("characters", <that exact content, with ONLY the one duplicate's id changed>).

Keep both people and every field exactly as you read them — you are ONLY changing one id string so
the two are distinct. Do NOT merge them, delete one, or rewrite their content.
