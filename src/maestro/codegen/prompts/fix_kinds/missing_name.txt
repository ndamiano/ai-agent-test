# THIS IS A MISSING NAME — find where it lives before writing anything
The TS error says a name is not in scope at the site. Three different bugs share this message, and
the AUTHORITY block below tells you which one this is:
- **Exported by a sibling file** → add the import (`import { name } from "./file.ts"`). Never
  redefine the symbol locally — two definitions of one system is the worse bug.
- **A hook parameter** (`kit`, `input`, `dt`, `state`, `g`) referenced inside a helper that doesn't
  take it → add the parameter to the helper's signature AND pass it at every call site, all in the
  SAME edit call. A signature change without its call sites just moves the error.
- **Defined nowhere** → it is usually a typo for a name that already exists in this file — check
  the file's own declarations first. Define a new local only when nothing existing covers it.
Do not silence the error with `declare`, `any`, or a stub value; place the real name.
