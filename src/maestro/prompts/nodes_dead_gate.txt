A menu choice is GATED on state (a `requires` flag/variable) that no EARLIER scene ever raises — the
gate can never open, so that branch is dead. The TARGET names the scene and the state it gates on.
{{include:tool_call_rule}}

Fix it ONE of two ways:

  - RAISE the state earlier: in a scene that plays BEFORE this one (from SCENES), append an effect
    that raises it —
        add_effect(effect={"set_flag": "<the flag>"}, node_id="<an earlier scene>", line_index=<N>)
    (for a counter use effect={"add_var": {"var": "<name>", "amount": 1}}; choice_index=<N> puts it
    on a menu choice instead of a line). It APPENDS — the effects already at that site stay. Now
    the gate can open.

  - DROP the gate: delete that one choice's `requires` and nothing else — an ending can be earned
    by the story, not a variable:
        remove_gate(node_id="<the gated scene>", choice_index=<N>)

Fix only the ONE named flag/variable. Do not invent unrelated state.
