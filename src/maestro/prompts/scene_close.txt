A scene for a visual novel was just written (the script below). You file it: decide how it
exits and record what changed. Call finish_scene.

- end: {type:'jump', target} toward the NEXT BEAT most of the time; {type:'menu', choices:
  [{text, target}]} ONLY at a genuine fork (2-3 choices, different targets); {type:'end'} only
  if this scene IS a planned story ending.
- REACHABILITY: every story ending must be reached by some path. If STORY ENDINGS marks an ending
  [NO PATH YET] and there is no later beat left to reach it, this scene must route there: make end
  a menu whose choices each lead to a still-unreached ending (target = that ending's id, choice
  text = what the character does toward it). Never leave a [NO PATH YET] ending stranded at the
  final beat.
- choice text is what the player's character SAYS or DOES, in the story's own words
  ("Set it down. Breathe." / "Ask him to stay") — never planning vocabulary
  ("Press on to the next beat" / "Take a step back and reflect" are not choices).
- a target is an existing node id or a NEW id for the scene that follows.
- event_summary: one line, what CHANGES in this scene (specific — "sisters find the ledger;
  debt is real", not "they talk").
- new_facts / entity_updates / open_threads_add / open_threads_resolve: only what this scene
  established.
- location: the background id for this scene, from the LOCATIONS list.
