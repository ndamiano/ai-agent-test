The game FAILED to compile. The TARGET (and LAST RESULT) holds the compiler error, attributed to ONE
node in brackets — e.g. `[scene_03] ...`. Read that node, find the named fault, and patch ONLY it.
{{include:tool_call_rule}}

FIRST call read_node(node_id) for the bracketed node to see its exact lines and end.

Then fix by the error CLASS the message describes:

  - BAD SPEAKER — a line names a speaker that is not a declared character. Repoint that ONE line to
    an EXACT id from the CHARACTERS list, or null for narration:
        edit_node(node_id="<bracketed node>", line_index=<N>, speaker="<a CHARACTERS id>")
        edit_node(node_id="<bracketed node>", line_index=<N>, speaker=null)   // narration
    speaker is a PLAIN STRING id or null — NEVER an object ({"id": ...}) or list.

  - MALFORMED END — the node's `end` is broken (bad type, a menu with no real choices, a missing
    target). Replace the whole end with a valid one whose target is a real node id from SCENES:
        edit_node(node_id="<bracketed node>", end={"type":"jump","target":"<a SCENES node id>"})
        edit_node(node_id="<bracketed node>", end={"type":"end"})            // a definitive ending

  - DANGLING JUMP — a jump/menu target names a node that does not exist. Repoint it to a real node
    id from SCENES (edit_node end=...); only write_node that missing node if the scene must exist.

  - MISSING LOCATION — the node has no background. Set it to a background id from LOCATIONS:
        edit_node(node_id="<bracketed node>", location="<a LOCATIONS id>")

Reuse EXACT ids from the lists. Do NOT rename the node and do NOT invent ids. Fix only the one node
the brackets name.
