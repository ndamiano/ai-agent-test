A combatant's `character` names someone who is not in this game's cast. The TARGET names the
combatant, e.g. `combatants[cb_foe].character: 'mara_lin' is not a declared character`.

The cast is FIXED — you do not invent or rename characters. Re-author ONLY that one combatant with
write_combatant, keeping every other field it already has and setting `character` to an EXACT id
from the CHARACTERS list below:

    write_combatant(combatant_id="<the combatant in the TARGET>",
                    content={"character": "<an id from CHARACTERS>", "stats": [...], "abilities": [...]})

`character` is a plain STRING id, never an object or a list. Restate the combatant's existing stats
and abilities so nothing is lost — you are fixing the one bad reference, not re-designing the fight.
Touch no other combatant. {{include:tool_call_rule}}
