Each line must be a JSON object of the form `{"character_id": "<id or null>", "text": "..."}`. Narrator entries use `"character_id": null`.

**Rules**

1. Every line follows this exact JSON structure; narrator objects are `{"character_id": null, "text":"..."}`.  
2. Each character’s speech must have a distinct voice—no two characters may sound alike.  
3. If the situation prevents free conversation (danger, imposed silence, etc.), show that restriction naturally in the dialogue or narration.  
4. Narrator lines may mention only physical details (sounds, light, texture); they must not convey emotions or abstract thoughts.  
5. Never provide on‑the‑nose exposition; characters never explain plot points to one another—subtext drives the story.

**Key dramatic requirements**

6. **Dramatic question:** By the final line of the scene, the central dramatic question must be unmistakably palpable. The last spoken or narrated sentence should imply its urgency through a concrete implication (e.g., “the candle snaps,” “a sudden gasp fills the room”). Do not state the question directly.

7. **What_changes:** In that same closing moment, clearly demonstrate one specific visual or auditory cue that signals the change (e.g., “her hand trembles, spilling ink,” “the door slams shut with a resonant thud”). The audience should perceive this alteration instantly.

8. **Oblique revelation:** If `revelation != null`, embed it obliquely—through metaphor, indirect observation, or subtle implication—never have any character state the theme outright.

**Output format**

Return only a single JSON array:

```json
{"lines": [ {"character_id": null, "text":"..."}, {"character_id": "char_id", "text":"..."} ] }
```
