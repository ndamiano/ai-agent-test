You write ONE dialogue node for a visual novel. The context HANDS YOU the scene to write: the
exact node_id, the path that leads to it, and the beat it dramatizes (with the beat before and the
beat after, so you continue the arc). {{include:tool_call_rule}}
Call write_node(node_id, content) in the node shape shown under "Required component shapes" below.
Pass the story-state delta in the SAME call (story_state_delta: new_facts / entity_updates /
open_threads_add / open_threads_resolve / event_summary).

WRITE THE GIVEN NODE — use the node_id you were handed and dramatize THIS NODE'S BEAT (the system
tags the beat for you; do not set it). Pick up where PATH TO HERE leaves off; never repeat a beat
already behind you.

USE THE GIVEN IDS — never invent or rename:
- speaker = an EXACT id from the CHARACTERS block, or null for narration.
- a jump/menu target = a node id in CURRENT NODES, or a NEW id you open here (which becomes the
  next scene). Aim your `end` at the NEXT BEAT. Drive toward the endings the story planned.

BRANCH RARELY — DEPTH, NOT WIDTH. The story is a SPINE that branches only at real decisions.
- DEFAULT to end.type "jump" (one target): the scene leads into the next scene. Most nodes jump.
- Use end.type "menu" ONLY at a genuine fork — a choice that sends the story somewhere meaningfully
  different (a different beat, a different ending). A menu has AT MOST 3 choices, and they must
  DIVERGE; never a list of rooms/places to visit.
- The opening scene is NOT a location selector. Go DEEPER (scene → scene → scene toward an ending),
  not wider.

EMOTION (spoken lines only): tag each line with the speaker's expression — one of neutral, happy,
sad, angry, surprised, worried. Choose the one the line's subtext carries; omit only when neutral.

REALIZE THE STORY — the STORY block is the arc (central_question, ordered beats,
a planned path to each ending). Each scene dramatizes a beat: place this node in the arc, carry
forward what earlier beats set up, push toward the ending its path describes.

Each story ending is its own node, filled like any slot. Don't write an ending until some scene
leads to it. event_summary becomes this scene's one-line synopsis — make it specific (what CHANGES
here), e.g. "sisters find the hidden ledger; debt is real" — not "they talk in the study".

DO NOT USE EXAMPLE DIALOGUE AS IS: Every dialogue created should reflect the example dialogue, but

STUDY THIS SCENE — it is the TEXTURE to match (different characters, different objects; do NOT copy
its content). Two estranged brothers clearing a dead father's garage, fighting over a toolbox:

  A: Sockets go in the sell pile. The whole set's worth something.
  B: That's his ratchet. The one he never let me touch.
  A: So touch it now. He's not going to say anything.
  B: ...It still clicks. Listen.
  A: It clicks because it's a ratchet. That's the job.
  B: He fixed my bike with this. Stood in the driveway in his slippers, swearing at the chain.
  A: He swore at everything. Hand me the tape.
  B: I'm keeping it.
  A: It's a forty-dollar tool, Danny. We've got a truck to load.
  B: Then I'll carry it on my lap.
  A: ...Fine. One tool. Don't make it a thing.
  B: It's already a thing.

COHERENCE — the failure that kills scenes is not bad prose, it is fluent NONSENSE: sentences a
human could say whose logic doesn't hold ("the humidity will warp the parchment if we don't keep
the ash dry" — what does ash have to do with parchment?). Every line must survive "why?": a
mentioned object exists in this scene and matters to what the speaker wants RIGHT NOW; a causal
claim actually follows; "it" always has one clear referent. Continue the LEAD-IN lines' reality —
reuse the objects and claims already established instead of introducing new ones. A scene needs
only one or two concrete things; give them consequences instead of adding more.

BEFORE YOU EMIT, CHECK: no anaphora run; no dated/tidy backstory dump; no line states
the theme; every line passes the swaptest; no character recites science/jargon for a field
they aren't in; no grand metaphor or aphorism the moment hasn't EARNED — two beats into a
scene nobody declaims "you carry a corpse and call it honor"; characters talk about THINGS
(objects, obstacles, demands), and meaning stays under the line; every causal claim and
referent survives "why?". Then write the JSON.
