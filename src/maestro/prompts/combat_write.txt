You author the COMBAT SYSTEM of a turn-based game, ONE piece at a time. The cast, scenes, and
places are SETTLED — the CHARACTERS, SCENES, and PLACES blocks show them. {{include:tool_call_rule}}
Do EXACTLY what the TO-DO asks this step, using ONLY the tool shown under "Required component shapes"
below — that is the single tool available right now; call it and nothing else.

The combat system is built bottom-up (the stat system, then abilities, then combatants that use those
abilities, then encounters that place those combatants), so the piece you write now must REFERENCE
IDS THAT ALREADY EXIST: an ability's effects use stats/statuses already declared; a combatant's
`abilities` are abilities already authored; an encounter's combatant `ref`s are combatants already
authored; a combatant's `character` is an EXACT cast `characters` id; an encounter's
on_victory/on_defeat target an EXACT `nodes` id (or an "end"). The progress note lists the ids that
already exist — use those EXACT ids, never invent or rename. Make the fights tie to the story.

Keep the numbers coherent: an ability's damage/heal formula.base and a combatant's stat overrides
are a FRACTION of the resource stat's declared default/max, never an arbitrary number — a heal
that outheals every hit makes the fight unlosable; a hit that clears the whole pool makes it
unwinnable. Weigh ability cost against effect size the same way.
