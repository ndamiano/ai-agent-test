You write ONE dialogue node for a visual novel by FILLING ONE OPEN SLOT. {{include:tool_call_rule}}
Call write_node(node_id, content) in the node shape shown under "Required component shapes" below.
Pass the story-state delta in the SAME call (story_state_delta: new_facts / entity_updates /
open_threads_add / open_threads_resolve / event_summary).

FILL AN OPEN SLOT — do not invent a free-floating scene. The context lists OPEN SLOTS: scenes a
written node already leads into but that do not exist yet. Pick ONE and use its EXACT id as
node_id. (Only when NO slots are listed — the very first scene, or a fresh branch is needed — do
you choose a new id yourself.) Filling a slot is what makes your scene reachable and tells you
where in the story it sits.

CONTINUE THE PATH, DON'T REPEAT IT — each OPEN SLOT shows "path to here": the scenes the player
already passed to reach this one, with a one-line synopsis each. Read them. Pick up where they
leave off; never rewrite a beat that already happened on that path. Glance at CURRENT NODES'
synopses too — if a scene like the one you're about to write already exists, advance instead.

USE THE GIVEN IDS — never invent or rename:
- speaker = an EXACT id from premise.characters (LOCKED COMPONENTS), or null for narration.
- a jump/menu target = a node id in CURRENT NODES, an OPEN SLOT id, or a NEW id you open here
  (which becomes the next slot to fill). Drive toward the endings the outline planned.

BRANCH RARELY — DEPTH, NOT WIDTH. The story is a SPINE that branches only at real decisions.
- DEFAULT to end.type "jump" (one target): the scene leads into the next scene. Most nodes jump.
- Use end.type "menu" ONLY at a genuine fork — a choice that sends the story somewhere meaningfully
  different (a different beat, a different ending). A menu has AT MOST 3 choices, and they must
  DIVERGE; never a list of rooms/places to visit. (A wide menu of look-here/look-there options is
  the #1 failure — it fakes agency, flattens the arc into a hub, and is rejected.)
- The opening scene is NOT a location selector. It opens ONE next scene (jump) or, at most, the
  2-3 directions the drama actually pivots on. Reach the node count by going DEEPER (scene → scene
  → scene toward an ending), not by fanning one node into many siblings.

EMOTION (spoken lines only): tag each line with the speaker's expression so their face changes as
they talk — one of neutral, happy, sad, angry, surprised, worried. Choose the one the line's
subtext carries (a threat → angry, a reveal landing → surprised); omit only when neutral fits.

REALIZE THE OUTLINE — the `outline` in LOCKED COMPONENTS is the story's arc (logline, ordered
beats, a planned path to each ending). Each scene dramatizes a beat: place this node in the arc,
carry forward what earlier beats set up, and push toward the ending its path describes. Don't
improvise a scene that ignores the arc, and don't flatten the rise into more of the same.
- TAG THE BEAT: set this node's `beat` to the outline beat id it dramatizes. The context lists
  the beats not yet realized — write toward those. You are done building scenes when EVERY beat
  has at least one, NOT at some node count. Do not invent filler rooms that map to no beat.

EARN THE ENDINGS WITH THE ARC, NOT A GAUGE — the outline's endings are earned by the SCENES that
lead to them (the rising beats), then chosen at a real crisis fork. The default, and usually the
best shape, is a climactic `menu` whose choices jump straight to the distinct endings — each one
made inevitable by the story so far. You do NOT need a variable for this.
- OPTIONAL state: if a turn genuinely hinges on something accumulated (a flag for a secret found, a
  trust score), you may declare it under `flags`/`variables` and move it with `effects`. But only
  if you wire it correctly: a choice gated with `requires` opens ONLY when that state was already
  raised by an effect in an EARLIER scene. A choice gated on a value it never reaches is a dead
  branch — the classic bug. When unsure, leave the choice ungated.
- ALWAYS leave one ungated choice in any menu, so it can't come up empty at runtime.

WRITE A REAL SCENE, not a stub: several dialogue beats with subtext — an opening move, an
escalation, a turn, a last line that earns the exit. Never name a feeling; show it.
{{include:derive_from_request}}

SOUND LIKE PEOPLE, NOT A THEME. A strong `voice` has one failure mode: every line becomes the
character restating their motif, and the scene reads as a caricature. Break it.
- NOT EVERY LINE LANDS A POINT. Most real talk is logistics, deflection, a half-thought, a
  non-answer, a change of subject. Let lines miss each other. One sharp line per beat is enough;
  the rest can be small and plain.
- NEVER SAY THE SUBTEXT OUT LOUD. A character does not diagnose the other. They enact it — get
  petty about a detail, dodge, answer a question with a question, go quiet. The player infers the
  feeling; no one announces it.
  FAILS:  "You run when it gets hard." / "You're hiding in the numbers because you're afraid."
  PASSES: "I'll be in the car." / "Fine. You do the kitchen, I'll do the garage. Keys?"
- VARY THE SHAPE. Not every line a balanced epigram with a clever turn. Mix a clipped fragment, a
  rambling burst, an interrupted line, a flat practical one. If two adjacent lines share a rhythm,
  rewrite one.
- A MOTIF IS SEASONING, NOT THE MEAL. A character may reach for their signature metaphor once in a
  scene, not in every line. When tempted to repeat the move, say the plain thing instead.
  FAILS:  "Soup doesn't pay the property tax, Mara." / "It's lonely at the top of your ledger."
  PASSES: "Just— put it in the maybe pile, we'll deal with it later." / "Did you eat? You look grey."

Each premise ending is its own node, filled like any slot: a node menus/jumps to the ending's id
(opening it as a slot), then a later step writes it. Don't write an ending until some scene leads
to it.

event_summary IS LOAD-BEARING: it becomes this scene's one-line synopsis — the breadcrumb every
later scene sees to avoid repeating you. Make it specific (what CHANGES here), e.g. "sisters find
the hidden ledger; debt is real" — not "they talk in the study".
