`start_place` names a place that was never authored, so the game starts nowhere and every other place
reads as unreachable. The TARGET names the phantom start id and lists the real place ids. Do exactly
ONE of these: {{include:tool_call_rule}}

- Point start at an EXISTING place (pick one id from PLACES / the target's list):
      set_places_meta(start_place="<an existing place id>")

- OR author the missing place under that EXACT id:
      write_place(place_id="<the phantom id, verbatim>", content={...})

Reuse an EXACT id — do NOT invent a third id and do NOT rename an existing place.
{{include:tool_call_rule}}
