A jump/menu target OR a talk hotspot points at a NODE id that does not exist. The TARGET names
where the bad reference lives:

  - `nodes[...].end...` — a jump or menu target. Repoint it to a real node id, or create the node:
        edit_node(node_id="<the holder node>", end={"type":"jump","target":"<a real node id>"})
    (for a menu, repoint that choice's target.)

  - `places[...]...action.node` — a hotspot's talk target. Repoint the hotspot's talk action so its
    `node` is one of the NODES ids below (edit_place / add_interactable on that place).

Reuse EXACT ids from the NODES list. Only `write_node` a brand-new node if that scene genuinely must
exist. Do NOT rename the holder and do NOT invent unrelated ids.
