A combat piece gates on or sets a FLAG that no scene declares. The TARGET names the exact site, e.g.
`abilities[cleanse].requires.flag: 'blessed' is not a declared flag`.

Fix it by RE-AUTHORING that one slice with its write tool shown under the skeleton below (an
ability → write_ability, a status → set_combat_meta, an encounter condition → write_encounter),
keeping every other field. Two valid fixes:

  - Repoint to a flag the story actually raises — set it to an EXACT flag id the NODES below show a
    scene setting, if one fits the intent.
  - Otherwise DROP the dangling flag: re-author the slice WITHOUT that `requires` gate (or without
    that world effect). A combat rule must not depend on a flag no scene ever raises.

Combat does not author story flags — it either points at an existing one or drops the reference. A
flag is a plain STRING. Fix only the named site; restate the slice's other fields.
